# Duplex Dots

DuplexDots-Bold.ttf is a modified version of Doto Bold, distributed under the
SIL Open Font License 1.1 in OFL-Doto.txt. Original copyright:

Copyright 2024 The Doto Project Authors (https://github.com/oliverlalan/Doto)

The derived family is named Duplex Dots. Only the zero outline is redesigned:
a conventional 5×7 rounded rectangle replaces the diamond-like original. Dot
contours, cap height, advance width, bearings, kerning and other glyphs are kept.

Rebuild with `python3 scripts/build-hero-font.py` (requires fontTools).
Doto-Bold.ttf is the unmodified source asset.
